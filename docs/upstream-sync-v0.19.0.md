## 保护二次开发功能的适配

- 登录、Sub2API 渠道同步、默认 Image2、余额刷新、退出登录清理凭据及中止请求的现有逻辑保留。生图接口只叠加上游超时配置，继续区分取消、超时和 HTTP/网络错误。
- 生图历史保留元数据按需读取、接近视口才加载缩略图、查看记录时加载原图的机制；优先复用新的持久缩略图，不恢复上游整批加载历史原图的方式。
- 缩略图保存在单独的 `image_previews` 库，不改变原图、画布、资产和历史记录的存储键；已有内嵌图片的读取逻辑保留，无需清空浏览器存储。
- 同一张图片的并发缩略图请求复用同一个任务，补生成仍按上游队列串行处理；删图时等待该图片的预览任务结束后一起清理，上传在预览生成期间取消时也清理新增原图与预览。预览不可用时回退原图。
- 默认深色主题、移动端导航、图片格式下载、Windows ZIP 文件名修复、构建标识更新检测和 Alien 品牌保留；原有本地 Agent 源码与 Codex 插件没有被上游旧插件覆盖。
