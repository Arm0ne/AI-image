# Docker Deployment

## Use the published image

```bash
git clone git@github.com:Arm0ne/AI-image.git
cd AI-image
docker compose up -d
```

Open `http://localhost:3000` on the server itself.

Compose binds the application port to `127.0.0.1` by default. In production, route your HTTPS domain through Nginx, Caddy, or another reverse proxy running on the same host to `http://127.0.0.1:3000`. If the proxy runs in a separate container, use a shared Docker network and forward to the app service on port 3000; the proxy container's `127.0.0.1` does not refer to the host.

Recreate existing containers with the corresponding `docker compose up -d` command to apply the binding change; restarting a container alone does not change its port mappings. This restricts direct public access to the application port. To reject IP-based access on ports 80/443 as well, configure the outer reverse proxy to reject requests with unmatched hostnames.

## Build locally

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## Documentation image

The documentation in `docs/` is a separate Next.js standalone application with server capabilities.

Its host port is also bound to loopback at `127.0.0.1:3001`; use that port for its domain's reverse proxy.

```bash
cd docs
docker compose up -d
```

To build it from the current source:

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

The main application container only runs Next.js. Canvases, My Assets, generation history, and API keys are stored in the browser by default, while prompt repositories are fetched directly by the frontend. No persistent data volume is required for this data.

## Optional analytics

No analytics are enabled by default. A deployment can enable GA4, Baidu Analytics, or both at runtime:

| Variable | Description |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 measurement ID (`G-XXXX`) |
| `ANALYTICS_BAIDU_ID` | Baidu site ID, the hash after `hm.js?` |

```yaml
services:
  app:
    image: ghcr.io/arm0ne/ai-image:latest
    ports:
      - "127.0.0.1:3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: e8263761cc5c32f5f7a855b8203b965a
```

SPA route changes automatically report page views to enabled providers. Only configure analytics IDs on sites you control, and do not commit them to the repository.
