# Codex App Plugin

Alien AI Studio Plugin connects Codex, the local Alien AI Studio Agent, and the web canvas. Enter `启动创作站` or the compatible phrase `启动生图站` in Codex to open [img.panlai.me](https://img.panlai.me) in your default browser and connect the site's Codex panel automatically.

The plugin source is in `plugins/alien-ai-studio-plugin/`, and the local Agent source is in `canvas-agent/`.

## Install

```bash
codex plugin marketplace add Arm0ne/AI-image
codex plugin add alien-ai-studio-plugin@alien-ai-studio
```

Start a new Codex task after installation so the Skill and MCP tools load completely, then enter:

```text
启动创作站
```

The default mode creates a canvas. You can also ask for the most recent canvas or the canvas picker.

## Local development

From the repository root:

```powershell
codex plugin marketplace add "$PWD"
codex plugin add alien-ai-studio-plugin@alien-ai-studio
```

The repository marketplace points to `./plugins/alien-ai-studio-plugin`. Reinstall the plugin and start a new Codex task after changing its manifest, Skills, or MCP configuration.

## Run the Agent directly

```bash
npx -y @arm0ne/alien-ai-studio-agent@latest
```

To add the MCP without the plugin:

```bash
codex mcp add alien-ai-studio -- npx -y @arm0ne/alien-ai-studio-agent@latest mcp
```

The Agent listens only on `127.0.0.1`. Plugin launches use a one-time ticket that expires after 60 seconds. The connection token stays in the URL fragment and is removed by the web app immediately after reading it.
