# Codex App 插件

Alien AI Studio Plugin 连接 Codex、本机 Alien AI Studio Agent 和网页画布。安装后，在 Codex 输入“启动创作站”或兼容口令“启动生图站”，插件会使用系统默认浏览器打开 `https://img.panlai.me`，并自动连接网站右侧 Codex 面板。

插件源码位于 `plugins/alien-ai-studio-plugin/`，本地 Agent 源码位于 `canvas-agent/`。

## 安装

```bash
codex plugin marketplace add Arm0ne/AI-image
codex plugin add alien-ai-studio-plugin@alien-ai-studio
```

安装完成后新建一个 Codex 任务，使新的 Skill 和 MCP 工具完整加载，然后输入：

```text
启动创作站
```

默认新建画布。也可以要求插件打开最近画布，或进入画布选择页面。

## 本地开发安装

在仓库根目录运行：

```powershell
codex plugin marketplace add "$PWD"
codex plugin add alien-ai-studio-plugin@alien-ai-studio
```

仓库内的 `.agents/plugins/marketplace.json` 已指向 `./plugins/alien-ai-studio-plugin`。修改插件清单、Skill 或 MCP 配置后，需要重新安装插件并新建 Codex 任务。

## 直接运行 Agent

不安装插件时也可以启动本地 Agent，再从网站连接：

```bash
npx -y @arm0ne/alien-ai-studio-agent@latest
```

手动为 Codex 添加 MCP：

```bash
codex mcp add alien-ai-studio -- npx -y @arm0ne/alien-ai-studio-agent@latest mcp
```

安装插件时不需要再手动添加 MCP。

## 安全边界

Agent 只监听 `127.0.0.1`。插件使用 60 秒内有效且仅可使用一次的本地启动票据；连接 token 只放在 URL fragment 中，网页读取后立即清除，不会发送到生产站点服务器。
